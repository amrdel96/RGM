# Security implementation checklist
Trusted authentication, server role guards and least-privilege repositories. Admin-only machine_internal. All forms validate on server with schema limits; distributed rate limiting and honeypot; origin/CSRF controls for staff mutations. Parameterized SQL and safe HTML rendering. No production secrets in git, logs or NEXT_PUBLIC variables.
Media upload tickets require permission or limited anonymous lead-upload session. Validate MIME and magic bytes, cap size/count, random object keys, quarantine/scanning, reject HTML/SVG and executables from customers; re-encode images, strip EXIF. PDFs remain private until reviewed. Seller uploads never publish automatically. Remote fetches must prevent private-IP/redirect SSRF.
Secure cookies/session expiry, provider password reset, login throttling, security headers and CSP tuned to approved providers. Verify webhook signatures and replay protection. Audit staff actions without logging passwords/tokens. Lead access limited to Admin/Sales; retention policy and export/deletion procedure need business configuration.
Threat tests cover IDOR, role changes, price leakage, sold caches, malicious upload, stored XSS, duplicate submissions and webhook forgery. Dependency audit and secret scan are release gates. This document specifies controls; it is not certification that all controls are implemented.
