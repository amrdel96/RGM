# Design system proposal

Visual thesis: precise industrial catalog, grounded in the existing RGM navy/blue identity, with real machine photography and compact technical information.
Original logo stays unchanged. Palette: logo navy #182765; logo blue #004F9E; existing secondary #3550A0; white surfaces; neutral #F3F5F8 and ink #172033. Color values are recovered evidence, not a replacement identity. Use status labels with icons/text, never color alone.
Typography proposal: Inter for English, Noto Sans Arabic for Arabic, self-hosted after license/asset verification. Until available use system sans-serif. Body 16–18px; labels 14–16px; generous Arabic line height 1.8, no letter spacing. Technical codes use tabular digits and bdi dir=ltr.
Layout: maximum 1280px, 24px desktop gutter/16px mobile, 8px spacing rhythm, 4–8px corners, subtle borders, minimal shadow. Avoid oversized blank heroes. Buttons at least 44px high. Visible keyboard focus. Respect reduced motion and 200% zoom.
Components: header/mobile menu, locale switch, search, filter drawer, card/list row, availability badge, spec table, gallery, dialog, field/error, consent checkbox, pagination, breadcrumb, empty/error/loading states, staff table and activity timeline. Logical CSS properties mirror RTL layout without reversing codes or all icons indiscriminately.
Machine cards prioritize image, title, code, year, location, key category specs and request-price action. No invented numbers/prices/testimonials. Empty inventory uses a useful sourcing CTA.
Review desktop 1440px, tablet 768px, mobile 390px in both directions. Check keyboard focus, modal trapping, labels, contrast, gallery loading and sticky action overlap.
